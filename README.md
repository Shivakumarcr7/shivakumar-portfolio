# Shivakumar Portfolio — V6

Editorial portfolio for Shivakumar Goud S Patil.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS

## Local setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
OR  https://shivakumar-portfolio-simple-7hbnygwum-shivakumarcr7s-projects.vercel.app/

## Build check

```bash
npm run build
```

## Photos

Keep the existing portfolio photos at:

- `public/photos/shivu-portrait.jpeg`
- `public/photos/shivu-acd26.jpeg`

The site does not require any image package.

## Deploy

Commit and push to the existing GitHub repository. Vercel can deploy the `main` branch automatically if the project is already connected.
